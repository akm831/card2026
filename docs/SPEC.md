# 次回試作仕様（2026-10-03の引き継ぎを整理）

決定事項は製品版の永久仕様ではなく、次の試作で検証する前提。ユーザーの引き継ぎを本書の基準とする。

## 核

1. 論点を読む：案件ごとに敵デッキと行動が異なる。
2. 人を配置する：人物が予告・論点・戦闘ルールへ介入する。
3. 事前に政治をする：準備戦で本戦の敵デッキそのものを変える。

## 戦闘と進行

HP、1ターン3コスト、手札使用、敵もコスト内で複数行動、敵の次行動公開、ターン確定前のUndo、人物・組織の盤面配置を維持。人物HPは設けない。

案件提示→主要論点確認→デッキ編成→準備戦3択から1つ→準備戦→論点弱体化→国会決戦→恒久カード報酬→短い後日談。1案件は原則2戦。

論点は敵の行動・デッキ構成へ直接反映する。対策成功は強い敵カードを弱いカードに差し替える方式を優先。単なる道中戦は設けない。国会決戦は予算委員会、法案審議、与野党協議、重要採決など案件に応じた名称とする。成立後の政策実行は短い文章・結果表示・必要なら簡単な選択で描く。

## 蓄積の3層

- 恒久カード：20枚デッキ、同名最大2枚。クリア・再戦で蓄積。
- 案件支援：準備による論点弱体化として表現。案件終了時に消滅。手札カードとして恒久化しない。
- 支持基盤：選挙で獲得し章をまたぐ。装備枠2〜3を検討中。

選挙は3案件程度の後に固定で行う総合試験。同じ20枚デッキを使い、支持基盤を得る。選挙専用デッキは作らない。

## 6属性とカードタイプ

カードタイプは攻撃・防御・準備・妨害・人物。属性は手法を表す別軸で、通常カードにも付与する。

|属性|思想|得意な手段|
|---|---|---|
|行政|処理・安定・手続き|防御、負担整理、行動遅延、安定運用|
|政治|根回し・人脈・動員|人物展開、コスト操作、連携、造反対応|
|報道|情報・予告・カウンター|先読み、予告介入、ドロー、追及への反証|
|経済|投資・効率・回収|先行投資、後の利益、リソース生成|
|地域|地盤・持久・復帰|回復、人物復帰、支持基盤連携|
|裏人脈|強制介入・禁じ手・代償|行動無効化、強い妨害、疑惑発生|

厳格な役割禁止はしない。全属性が基本的な攻防を可能とし、達成手段を変える。固定の属性組み合わせボーナスを大量追加するよりカード相互作用を優先。

## 人物と代償

人物は数値バフだけでなく、予告延期・順序変更・情報公開、論点カウンター、属性使用への反応などのエンジンを持つ。各属性1〜2人から試す。敵も人物能力停止・手札戻しなどで干渉する。

裏人脈の代償は単純なHP消費より政治的な結果を優先。例：行動無効化の代わりに敵デッキへ疑惑追及を追加。まず案件内で完結し、案件をまたぐ借り・疑惑は導入しない。

## 将来のPvP

シングルを最優先。PvPのために複雑化・バランス変更をしない。ただしカード、属性、人物、行動、予告、論点、状態は再利用可能なデータにする。

効果を「AIの次行動」ではなく「予告された行動1つを延期・無効化」と定義する。将来はPvP用調整値・禁止・効果差し替えを設けられる余地を残す。

PvPの同時プロット・一部公開・対応・解決や、論点争奪による専用勝利条件は未実装・未確定。カード資産を共通化し対戦ルールを専用化する案を将来候補とする。PvEの敵デッキ事前弱体化を、そのまま対人へ持ち込む前提にはしない。


## v13 検証方針：初回は入門、その後は論点への適応

最初の案件全体（準備＋本戦）は、単純使用の自動プレイで各初期デッキ75〜85%程度を目標にする。人間の初見勝率を保証する数値ではない。予告を読んで上手く使う方策は別に測定し、熟練者の勝率を80%に強制しない。

入門用の敵は初期デッキによらず同一。HP30、基本3コスト、初期5枚/以後1枚、保持手札は維持する。初期カード構成と共通カード性能を調整する。

後続では論点の配分、人物干渉、攻撃/防御の組み合わせを変えて、デッキ編成・準備選択・温存の理由を作る。必要なカードを運だけに依存せず得られるよう、報酬はランダム2枚＋任意の1枚。v13は同じ「夢の超特急」の再戦条件として入門/財源採決/地方報道の3段階を検証する。新しい歴史案件・選挙・支持基盤は未実装。

1回クリアで実戦1、2回クリアで実戦2を選べる。入門への再戦も残す。全デッキ/全準備が常に同じ順で難しくなるとは限らず、得意な論点による戦術差は残す。
