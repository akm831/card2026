# Godot UI試作02

手札の全文を共通詳細欄へ移し、カード選択→使用→必要なら予告を指定する操作へ変更。手札はコスト・短い名前・属性/タイプ・仮イラストを表示。5種類のSVGは将来のカード別イラストへ交換する枠のための仮素材。

全体スクロールを廃止し、横画面1280×720を基準に幅を拡張。人物の全文と配置解除、戦闘ログ、設定は小窓。Noto Sans JPのwght=650を明示。通常7枚は横一列。8枚以上の一時的な超過時だけ手札欄を横スクロールし、選択したカードを捨てる。効果が長い場合は詳細欄2行＋全文ボタン。

HP、コスト、カード効果、乱数、成長、敵AIは変更しない。敵人物については表示領域だけ確保し「次の検証で追加予定」と明記。固定人物・停止/退場ルールと勝率検証は次の独立した改修で行う。モックアップの仮文言は採用しない。

## 確認

- HTMLとの48戦・896状態比較、保存往復は一致。
- 4デッキの開始・行動演出・Undo・ターン終了・保存再開はheadlessで確認。
- 1280×720/1560×720、手札7枚・人物3人・予告3件、詳細選択と手札超過時の画面範囲を確認。
- これは座標による確認。実機の見た目・タップしやすさ・音はユーザーの確認が必要。

APKの署名については GODOT_ANDROID.md を参照。ローカルAPKは試作01と同じローカル鍵。GitHub Actionsは固定鍵のSecretsがない場合、実行ごとに異なる鍵を使う。
