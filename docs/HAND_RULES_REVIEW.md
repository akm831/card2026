# 手札保持・通常ドロー枚数の比較（v10ベース）

## 条件

ゲーム数値は変更せず、実験用VM内だけで手札ルールを変える。正式に遊べるHTMLはv10のまま。

- 現行：プレイヤーはターン終了で手札を捨て、毎ターン5枚。
- 自分1枚：プレイヤー初期5枚・残り手札保持・毎ターン1枚。敵は現行の手札交換5枚。
- 自分2枚：プレイヤー初期5枚・残り手札保持・毎ターン2枚。敵は現行。
- 双方1枚：プレイヤーと敵の初期5枚・保持・毎ターン1枚。敵は予告したカードのみ捨てる（延期された行動のカードは最初に使用した時点で捨てる）。

プレイヤーは上限7枚。追加ドローは残し、超過分を自動で選んで捨てる。優先順位は負担、配置済み同名人物、その他の低価値カード。上限超過以外の自由な捨て札は導入していない。敵の上限選択は実装していないため、双方1枚は完全な対人対称ルールの検証ではない。

4デッキ×2難易度×3準備×2bot×4方式×100組＝19,200組の準備戦＋本戦。最大38,400戦。準備敗北も本戦へ進む。固定seedから開始。カード数値・敵コスト3・HP30を維持。追加ドローと投資は維持。

予告対応botには「今使う価値がなければ終了して温存」を追加。攻撃準備も評価する。未来の複数ターンを最適化するbotではなく、人間の勝率とは異なる。前の比較botから判断を変えているので、過去の別テスト数値との単純比較はしない。

## コストと手詰まり

自分1枚では行政・経済で毎ターン平均約1.2コスト、裏人脈で約1.5コストが余る（準備・本戦を合算）。行政・経済は約6割のターンで「コストが余り、現在使えるカードがない」状態になった。単に手札ゼロというより、重複人物・対象のないカード・負担などで行動できない問題を含む。

地域＋報道は追加ドローが多く、ほかの属性より供給を維持できる。敵も1枚にした場合、通常97〜98%、上級84〜94%に対し、裏人脈は通常8〜16%、上級2〜6%。敵の補充を変えるだけでは属性差を解消できない。

タイムアウトは全条件ゼロ。初期手札・保持・1枚補充・上限、敵の1枚補充と使用カードの除去を実験スクリプト内で検証。実ブラウザの新手札UIはまだ作っていない。

## 結論と次の検証案

手札保持の方向を否定する結果ではない。一方、現行カードに通常ドロー1枚をそのまま適用する方式は採用しない。

毎ターン1枚を維持するなら、次を小さく組み合わせて再検証する：

1. 報道以外にも、条件付き補充・回収・交換を配置する。単純に全属性へ強いドローを増やさず手法を変える。
2. 不要な人物や対象なしカードを交換できる機会を用意する（例：1ターン1回、1枚捨てて1枚引く）。負担まで無料で除去できるかは別途検討。
3. 裏人脈の疑惑は補充を減らすと長い戦闘で蓄積しやすいため、発生頻度・対処手段を見直す。
4. 敵も保持する場合のコスト使用量・テンポ・人物成長を確認する。

自分だけ2枚でも裏人脈は通常13〜17%で、枚数を増やすだけの解決は避ける。正式版はv10を維持し、次の試作で補充・交換・負担の設計を一緒に検証する。
