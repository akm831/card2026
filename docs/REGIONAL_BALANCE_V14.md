# v14 地域＋報道：要因診断と調整

## 結論

人物のドロー・世話役の回復・成長攻撃が主因という当初の見立ては、今回の入門戦では支持が弱かった。通常カードの追加ドローを除去したときの低下が大きく、手札補充と公開予告への対応を組み合わせられることの影響が大きいと考えられる。

ただし、削除実験では空振りのカードが残り、代替カードを入れていない。効果同士の相互作用もあるため、低下幅をその効果の独立した寄与や適切な調整幅と読み替えない。人間の体感は未検証。

## v13の削除診断

地域初期デッキ、準備＋本戦、3準備/2方策/3段階、各条件100回。同じ初期乱数から開始。人物ドローは介入・成長時・成長後攻撃をすべて除去。世話役回復は通常・成長時・成長後を除去し、カード自体の回復は残す。成長攻撃は地域/報道の＋4を除去。他属性の成長は変更しない。

通常補充は記者説明/裏取り/再登板の代替ドローを除去。予告対策は反証公開と地域との協議の介入を除去し、防御部分を残す。診断VMでは説明文を差し替えない。

以下は予告評価方策、3準備の等重み平均。各準備100回なので、小さな差は誤差の可能性がある。

| 除去した効果 | 入門 | 実戦1 | 実戦2 |
|---|---:|---:|---:|
| なし | 97.3% | 74.7% | 77.7% |
| 新聞記者の追加ドロー | 96.3% | 74.7% | 75.0% |
| 世話役の回復 | 95.0% | 68.7% | 67.3% |
| 地域/報道の成長攻撃 | 97.3% | 74.7% | 77.0% |
| 通常カードの補充 | 81.3% | 45.3% | 47.7% |
| 通常カードの予告対策 | 95.0% | 72.0% | 64.0% |

人物ドローの全除去や成長攻撃の除去は、今回の初期構成では入門勝率をほぼ変えなかった。成長後の能力が働く回数や別の収集デッキでは結果が異なる可能性がある。世話役回復は実戦での差が大きいが、入門の単純使用をさらに難しくするため今回は維持。

## 採用した調整

1. 記者説明：コスト1、防御3、**次ターンに追加1枚**。当ターンの防御・追加ドロー・別の対策を続ける効率を抑え、補充総量は残す。
2. 裏取り：コスト1→2、即時ドロー2は維持。補充のために残りコストをどう使うかを判断する。
3. 新聞記者：介入・成長時・成長後攻撃の追加ドローを、共通で各ターン1枚まで。通常カードのドローは別枠。今回の初期構成でこれだけの勝率変化はほぼなかったが、重複発動を抑える明確な規則として採用。
4. 公開討論：コスト1・攻撃6→7。沿線説明会：コスト1・攻撃6→8。単純使用の入門勝率を維持するため、補充効率から直接攻撃へ強さを移す。

世話役の回復、成長攻撃＋4、HP30、基本3コスト、通常1枚/保持、敵AI/案件構成は維持。次ターンの予約ドロー枚数を自分の欄に表示し、Undo/保存/ターン切替で予約と人物ドロー枠を管理する。旧版とは保存が独立。

## 検証と残る課題

削除診断7,200＋通常カード診断5,400＝12,600案件。最終v14全構成14,400＋v13同方策比較3,600＋v14別乱数1,800＝19,800案件。合計32,400案件、打ち切り0。調整途中の候補は総数に含めない。

回帰は人物の共通枠/重複防止/停止/ターン切替/Undo、記者説明の当ターン未補充/次ターン補充/予約表示、カードコストを含め通過。予約ドローと投資、手札超過等は既存戦闘状態として保存する。実ブラウザ描画や人間の面白さは未確認。

地域＋報道の予告評価は依然高く、特に入門の差は未解決。全効果を削って勝率だけを下げる対応は採用していない。今回の調整は補充のコスト/タイミングを変えた段階であり、バランス完成とはみなさない。以下を継続する。

- 人間の初見試遊で、次ターン補充と2コスト裏取りが理解でき、入門が難しくなり過ぎないか確認する（Issue #3）。
- 複数の乱数・プレイヤー方策・収集構成で、差の再現性とドロー必須化を確認する（#1/#2）。
- 敵の通常1枚による選択肢不足と、完全公開の予告に対策できる効率を、カード性能の問題と分けて検証する（#4）。
- 次の変更では補充量をさらに削る前に、対策と攻撃の両立、敵の論点/行動頻度を比較する。

再現コマンドはdocs/TESTING.md。報告はreports/ablate_regional_v13.json、ablate_regional_cards_v13.json、regional_baseline_v13.json、balance_v14.json、regional_v14_holdout.json。
