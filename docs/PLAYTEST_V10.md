# v10 人による試遊の進め方

目的：説明不足とゲーム判断の問題を切り分ける。v09と数値を変えず、効果確認・ログ・メモを追加。

## 短い試遊

1. 行政＋政治か地域＋報道を選び、論点とデッキを確認。
2. 準備を選んだ理由を一つ決める。推奨する正解は提示しない。
3. 最初は効果確認を使わず数ターン遊び、何に効くか迷うカードがあるかを見る。
4. 迷った場面で「効果を確認」を開き、予測が理解を助けるか確認。
5. 人物の進捗・成長連携・防御が、ログと実際の結果で理解できるか確認。
6. クリア・敗北後、「試遊メモ」に難しさ、迷ったカード、準備の選択理由、人物の貢献／次回の改善案を記録。
7. 余裕があれば同じデッキで違う準備を選ぶ。無理に全組み合わせを遊ばない。

評価すること：正解を暗記して同じ手順になるか／防御・攻撃・人物保護を迷えるか／負けた理由と改善策が分かるか／予測が役立つか、考える余地を奪うか。

## 予測の範囲

現在の手札・公開予告・盤面だけで計算。確認で乱数や戦闘状態を変更しない。対象カードは予告ごとの結果を示す。カードを使い、そのままターン終了した場合の直接的な攻撃・防御を表示。ドローの具体的内容・追加カード使用・人物干渉・次ターン以降は予測対象外。ゲームの勝敗を保証する機能ではない。

## 記録

メモは現在のブラウザに保存。外部送信なし。保存時のデッキ・準備・戦闘状態も添付してJSONでダウンロード可能。メモに個人情報を入れる必要はない。

## 検証

効果確認の無変更、対象別予測、実際の防御結果との一致、メモ保存と文字列エスケープを回帰検証。v09/v10の480組の同一seedキャンペーンで、表示ログを除く戦闘・進行・乱数の一致を確認。これは数値を変更していないことの検証で、人の試遊結果ではない。修正版の実ブラウザでの表示・操作確認は未実施。
