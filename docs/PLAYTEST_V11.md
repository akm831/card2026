# v11 人間による確認の手順

`prototypes/kasumigaseki_cards_v11.html`をブラウザで開く。旧版とは保存が独立。初期デッキを変える場合は「最初から」を押すと所持カード・進行を消去する確認が出る。試遊メモは残る。

1. 行政＋政治、地域＋報道、裏人脈＋政治、経済＋行政を各1案件。初見では通常で確認。
2. 初期5枚、使用しなかったカードが残り、次ターンに通常1枚増えることを確認。
3. 追加ドローを使わずに待つ判断と、ドローにコストを使う判断を比べる。毎ターン3コストを使い切る必要はない。
4. 8枚以上になったら捨てるカードを選ぶ。「1手戻す」で捨てる前に戻る。追加ドローもUndoで同じ結果になる。
5. 人物を配置し、成長条件・成長時効果・翌ターンの能力を確認。敏腕官僚の防御は消えても、成長後は翌ターン開始に5を生成する。
6. 更迭や停止は予告時に対象が決まる。対象なしの予告後に人物を置いても、その予告の対象にはならない。
7. 準備戦で勝ったとき、対応する本戦予告の名前・攻撃が弱い版になることを確認。
8. 「試遊メモ」に、何もできないターンが苦痛だったか、持ち越しが判断を増やしたか、毎回同じ準備を選んだかを記録。

特に確認したい点：追加ドローなしのデッキが面白いか、地域＋報道が易しすぎないか、裏人脈の疑惑が遅れて来ても代償を感じるか、予備資金の翌ターンドロー減少が納得できるか。

自動検証は画面の見やすさ、スマートフォンでの操作、楽しさを判定しない。人間による確認が終わるまでv11は検証用試作として扱う。
