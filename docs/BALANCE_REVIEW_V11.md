# v11 検証結果と残る懸念点

## 採用した試作ルール

基本は双方HP30・3コスト・20枚/同名2枚。双方初期5枚、2ターン目から通常1枚。未使用手札を持ち越す。追加ドローはカードの選択に任せる。固定5枚への補充は行わない。

上限7枚。プレイヤーは超過分を選んで捨てるまで使用・終了を停止し、捨てた操作もUndo可能。敵は弱いカードから上限まで捨てる。敵も選択した予告カードのみ消費し、未使用手札を保持する。

## 比較方法

1. v10の効果値を変えず、双方保持・通常1枚に変更した比較：8デッキ×2難易度×3準備×2方策×100乱数＝9,600案件。16枚共通・4枚交換で追加ドロー型と効率型を比較。結果はreports/deck_draw_tradeoff.json。
2. v11本体：4系統×3構成（初期・効率・追加ドロー）×2難易度×3準備×2方策×100乱数＝14,400案件。結果はreports/balance_v11.json。

各案件は準備戦から本戦まで実行する。準備戦で負けても本戦へ進む。初期構成は実際の初期所持カード、比較構成は対象カードを所持済みと仮定。追加ドロー型と効率型は16枚を共通にするが、属性や防御効果も変わるため、ドロー枚数だけの因果比較ではない。効率型にも元からドロー効果を持つカードがあり、完全なドローなし比較ではない。

簡易方策と、公開予告を評価する方策の2種類。後者も単発行動の評価であり、将来の最適手順を探索せず、隠れたカードを読まない。手札上限でのドロー価値を7枚までに補正したため、v10比較との方策は完全一致しない。敵の手札上限もv11で実装した。**以下は人間の勝率ではない。**

## 構築したデッキの比較（通常・予告評価）

| 系統 | 効率型 | 追加ドロー型 |
|---|---:|---:|
| 行政＋政治 | 41～54% | 85～85% |
| 地域＋報道 | 89～93% | 90～94% |
| 裏人脈＋政治 | 84～95% | 95～100% |
| 経済＋行政 | 74～82% | 96～99% |

初期デッキは、重複人物を各1枚へ減らし、各系統に新しい通常カード2枚を入れているため、16枚共通の構築比較とは別物。カード収集による強化余地はあるが、追加ドロー型の高勝率を完成バランスとはみなさない。

## 変更したカード・操作

- 行政の手順確認をコスト2・攻撃11・防御4へ。強引な動員を攻撃14・防御3へ。疑惑追及を攻撃5へ。
- 記者説明は防御4・ドロー1、裏取りはコスト1・ドロー2。新聞記者は介入ドロー各ターン1回、成長まで介入3回。成長後の追加ドローは最初の報道攻撃に限定。
- 地元の声はコスト2・攻撃8、人物による追加攻撃1。調査報道はコスト2・攻撃8。地域の支えは防御5・回復1。成長した世話役の追加回復は1。反証公開はコスト2・防御2を併せて得る。
- 6属性に各1種類、計6枚の通常カードを追加。初期デッキは2属性各10枚、人物各1枚。
- 成長攻撃の説明・ログを実効果の＋4へ統一。最初から選び直す操作を追加。v11保存を旧版から分離。

## 優先順位つきの懸念点

| 優先 | 懸念 | 現状と次の確認 |
|---|---|---|
| 高 | 地域＋報道が強い | 回復・介入・補充の循環が強く、初期構成でも高勝率。通常の入門向けとして許容できるか、人間の試遊で判断。全体の敵火力を上げると裏人脈を再び壊すため避ける。 |
| 高 | 追加ドローがほぼ必須になる構成 | 行政の比較効率型は41～54%、ドロー型85%。経済・裏人脈の収集ドロー型はほぼ勝つ。全属性に無料ドローを配る対応はしない。強い循環のコストや、補充なしで待つ価値を次の調整対象にする。 |
| 高 | 人間の体感は未確認 | VM検証は実ブラウザの描画・スマートフォン操作・楽しさを判定できない。PLAYTEST_V11.mdの手順で確認。 |
| 中 | 手札が尽きてコストを余らせる | 保持＋1枚方式では意図的に起きる。負担カードや重複人物での行動不能と、温存判断を区別する。報告にblockedEnds/unusedEnergy等を保存。全コストを毎ターン使う目標にはしない。 |
| 中 | 予備資金で翌ターン0枚になる | 元のドロー減少の代償が重くなった。説明には翌ターン−1枚と表示。人間が使う価値を感じるか要確認。 |
| 中 | 疑惑の到着が遅い | 敵も1枚ずつ引くため、山札へ追加した疑惑がすぐ来るとは限らない。即時HP代償へ戻さず、発生の実感と無効化連打の優位を確認。 |
| 中 | 敵の保持手札で予告の選択肢が減る | 敵も3コストを必ず使い切らない。無効化された行動もカードを消費するので妨害価値が増える。予告の強さ・行動数の推移を今後測定する。 |
| 中 | 準備選択が固定化する | デッキごとに3準備を比較しているが、勝率だけで選択の面白さは断定しない。地方を直接弱体化できない構成は現仕様として表示。 |
| 低 | 初期人物の重複で詰まる | 初期デッキの人物各1枚で緩和。収集後は各2枚も選べる。重複配置不可は維持。 |
| 低 | 超過・Undo・延期・保存の不整合 | 回帰テストで保持、上限選択、Undo、無効化の消費、敵コスト上限、保存独立を確認。UIの実操作は別途。 |

## 判定

通常1枚方式は実装・調整できる。初期構成は壊滅的な勝率から回復したが、系統間・収集構成の差は残る。**v11は人間の検証に進める試作であり、製品版の最終リリースではない。**現在の差を解消するために、選挙・新管理リソース・PvPを追加しない。

## 別乱数での初期構成確認

SEED_BASE=246810、各条件200案件。4初期デッキ×2難易度×3準備×2方策＝9,600案件を追加。最初の比較と異なる乱数系列で、追加調整をせず確認した。主比較14,400件と合わせてv11は24,000案件（準備＋本戦48,000戦）、打ち切り0。v10条件の比較9,600件は別集計。

| 初期デッキ | 通常・簡易方策 | 通常・予告評価 | 上級・予告評価 |
|---|---:|---:|---:|
| 行政＋政治 | 64～66% | 70～75% | 52～54.5% |
| 地域＋報道 | 82.5～87.5% | 93.5～98% | 77.5～92% |
| 裏人脈＋政治 | 54.5～58% | 69～70.5% | 50～55% |
| 経済＋行政 | 80.5～92.5% | 89～95.5% | 74～83.5% |

再現：`VARIANTS=starter TRIALS=200 SEED_BASE=246810 REPORT_PATH=reports/balance_v11_holdout.json node tests/balance_v11.cjs`。200件でも50%付近の95%区間は概ね±7ポイント。複数準備と2方策を同じ種で測るため、それらを独立標本として合算しない。
