# v17：対象説明・ランダム報酬・属性組み合わせ（2026-10-04）

## 実装した変更

カード自身の属性、効果の対象属性、案件の論点を区別した。敵の予告は「属性：政治／論点：議会対立」のように2種類のラベルを表示する。カードには「カード属性」を明記する。

| カード | 新しい対象説明 | 効果の対象 |
|---|---|---|
| 採決の調整 | 政治属性の攻撃予告すべての攻撃力を−4 | 政治。人物への干渉は止めない |
| 地域との協議 | 地域属性の攻撃予告すべての攻撃力を−4。ブロック3 | 地域 |
| 反証公開 | 報道・裏人脈属性の攻撃予告1つを無効化。ブロック2 | 報道／裏人脈 |
| 調査報道 | 攻撃7。未無効化の【疑惑】論点の予告があれば＋4 | この追加攻撃条件は明示した論点条件 |

属性は「どう解決するか」、対象は効果の説明が指定する相手、論点は案件の問題分類。同じ属性の敵だけに作用するという一般ルールは設けない。報道カードが裏人脈に対抗するなどの相互作用を残す。

対象判定は単なる名前変更ではなく、`reduceAff` と `affs` で属性を参照する。現行案件では財源＝行政、議会＝政治、地方＝地域、報道＝報道、疑惑＝裏人脈。共通防御は無属性。この対応なので既存戦闘の対象範囲は維持されるが、将来は同じ論点にも別属性の行動を置ける。予告に対象がない妨害は使用不可とし、対象数・効果プレビュー・実処理を同じ判定に揃えた。準備戦の差し替えは従来どおり論点を使う。

資金調達の【調整の負担】は捨て札への追加、予備資金は次ターンのドロー減少、再登板／調整役の交代は配置解除した人物の回収、と実処理に合わせて説明を修正。数値は変更しない。

## 報酬

勝利ごとの恒久報酬を、ランダム2回＋選択1枚から**完全ランダム5回**へ変更。全属性の使用可能カードから、カード単位で同じ確率の独立抽選。同じパックに同名が複数出ることもある。属性ごとの抽選確率を均等にしたり、未所持を保証したりはしない。レア度別の重み付けはまだ実装していない。

所持上限2枚を超えた分は交換ポイント＋1、4ポイントで任意カード1枚の交換を維持。選択報酬画面は廃止し、パック表示から後日談へ進む。勝利確定前のUndoは従来どおり。初期20枚・5保存枠・試遊モードを維持する。v17保存は旧版と独立。

4初期構成×1,000セット×連続10勝のパックだけのシミュレーション（交換なし、戦闘なし）では：

| 勝利回数 | そのパックで増える所持コピー数の平均 | 新しいカード名の平均 | 追加コピー0枚の割合 |
|---|---:|---:|---:|
| 1勝目 | 4.01 | 3.23 | 0.0% |
| 5勝目 | 3.38 | 1.90 | 0.3% |
| 10勝目 | 2.42 | 1.00 | 3.2% |

40,000パックで「追加コピー＋交換ポイント＝5」を確認。重複が増えるほど新規カードは減る。交換はこの試験で行っていないので、実際のカード集めの速度を保証する値ではない。

## 2属性の全15組み合わせ

低い値はその属性組み合わせが成立しない証明ではない。12候補しか探索しておらず、候補の組み方・ボットの操作に依存する。未採用構成や人間の戦術で変わる可能性がある。固定属性ボーナスは追加していない。

実際の20枚例は `DECK_EXAMPLES_V17.md`、機械可読の15配方は `reports/deck_examples_v17.json`。ゲーム内で自動獲得・自動編成する機能ではない。

## 初回のランダム5枚から組み替える試験

第1ステージを単純使用で実際に突破し、獲得した5枚だけを引き継いだ。4種類の既存候補を使う300試行の保守的比較では、選定候補が初期構成のままになることが多く、報酬後の上昇を十分確認できなかった。

追加試験では各初期100試行の成功者に対し、上の15配方を実所持へ合わせ、不足分を初期カードで補った。組成が同じ候補はまとめ、初期構成も含めた。各候補を測定用とは別の3つの訓練戦（準備3種を各1回）で比較して選び、実測用の乱数で第2ステージを測定した。新属性は2属性だけでなく初期カードを補う第三属性になる場合もある。交換は使わない。

| 初期構成 | 第2：初期のまま | 第2：実報酬を使う混成 |
|---|---:|---:|
| 行政＋政治 | 63.3% | 67.4% |
| 地域＋報道 | 70.3% | 69.4% |
| 裏人脈＋政治 | 72.9% | 73.3% |
| 経済＋行政 | 70.2% | 65.1% |

予告評価ボットの値。単純使用では62.5→63.3、44.3→47.0、56.2→58.9、55.3→52.9%。勝率改善の保証は得られなかった。完成形の配方を少数の実所持へ無理に合わせると、元の連携を壊す可能性がある。訓練3戦も少なく、選定のノイズが大きい。この結果だけでランダム5枚が悪い、特定属性が弱いとは断定しない。初回は有用カードの少数差し替え、収集後に新属性の人物と通常カードをまとめて試す、という編成案内を今後確認する。

## 検証範囲

- 全15組み合わせの測定13,500案件。
- 5組み合わせの別乱数測定9,000案件。
- ランダム5枚の通し測定12,744案件。
- 実所持に合わせる追加試験の測定4,396案件。
- 合計39,640測定試行（同じ乱数を共有する比較を含む）。測定打ち切り0。候補選定の訓練試行はこの件数に含めない。
- パックのみ40,000回は戦闘試行数に含めない。
- 既存回帰と属性対象／プレビュー／Undo／対象なし／報酬計数のテスト通過。

ボットの勝率であり、人間・実ブラウザ・モバイルの確認は未実施。各セル100／200回のため小差を断定せず、同じ乱数を使う準備・構成間の平均を独立した3倍の試行数と扱わない。上位配方を選んだ後の別乱数でも強さが続く例はあるが、全カードの最適解や全ゲームのバランスを保証しない。

カードバトルの単調さに対する新しい敵の戦術・イベントは今回は実装していない。今回の中心は説明の整合、報酬の変更、属性組み合わせの検証。完成デッキの強すぎる連携と、通常収集段階の遊びやすさを次の調整課題とする。
