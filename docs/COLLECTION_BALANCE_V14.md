# v14：収集後のデッキ比較（2026-10-04）

## 判断

ユーザーの実プレイでは入門は楽勝というほどではない。入門設定を保ち、カード収集後の地域＋報道が全般的に優位になるかを比較した。今回の範囲では一律の追加弱体化は行わず、ゲーム本体はv14を維持する。地域＋報道は引き続き有力だが、全カード所持の財源・議会中心では経済＋行政の方が高く、地域だけが収集によって突出する根拠は得られなかった。バランス完成の宣言ではない。

## 条件

- HP30、基本3コスト、手札保持＋通常1枚、敵予告、カード性能、敵AIは変更なし。
- 初期所持は実装どおり初期デッキ中の各カードを2枚所持。
- 「選択報酬2枚」は初期所持＋不足コピー最大2枚。ランダム報酬は使わず、獲得に必要な周回数は仮定しない。
- 「2属性全所持」は各初期デッキの2属性の全カードを2枚ずつ所持。他属性の混成は未検証。
- 各系統・所持条件で初期デッキを含む12候補を同じ回数だけ探索。固定乱数で最大6／12回の合法交換を試行し、20枚・同名最大2枚を維持。
- 候補を実戦1・2×3準備×各20回で評価し、その平均が最大の1構成を選ぶ。準備ごとに別デッキは選ばず、準備戦と本戦も同じ構成。
- 選定用とは別の乱数で入門・実戦1・2×3準備×各200回を測定。初期デッキも同じ測定乱数で比較。
- 予告評価ボットのみ。ブラウザ・人間のプレイテストではない。単純使用の入門目標75～85%は今回の調整対象にしない。

探索11,520案件＋初期デッキの選定確認24案件、測定21,600案件。測定の打ち切り0。既存の `npm test` 全通過。探索の打ち切り集計はレポートに保存していないため、測定の打ち切りと区別する。

## 測定結果

3準備を等重みした平均勝率（%）。実戦は同一題材の条件違いであり、新しい歴史案件ではない。

| デッキ | 所持／編成 | 入門 | 実戦1：財源・議会 | 実戦2：地方・報道 |
|---|---|---:|---:|---:|
| 行政＋政治 | 初期 | 85.3 | 67.8 | 59.8 |
| 行政＋政治 | 選択報酬2枚 | 91.3 | 74.7 | 65.2 |
| 行政＋政治 | 2属性全所持 | 88.8 | 78.7 | 71.5 |
| 地域＋報道 | 初期 | 96.0 | 70.2 | 72.2 |
| 地域＋報道 | 選択報酬2枚 | 97.5 | 78.7 | 79.5 |
| 地域＋報道 | 2属性全所持 | 97.8 | 81.2 | 77.5 |
| 裏人脈＋政治 | 初期 | 91.2 | 73.2 | 64.0 |
| 裏人脈＋政治 | 選択報酬2枚 | 93.0 | 77.5 | 68.0 |
| 裏人脈＋政治 | 2属性全所持 | 91.2 | 80.0 | 66.2 |
| 経済＋行政 | 初期 | 90.8 | 72.7 | 63.2 |
| 経済＋行政 | 選択報酬2枚 | 92.7 | 77.0 | 69.0 |
| 経済＋行政 | 2属性全所持 | 95.8 | 84.2 | 76.2 |

地域全所持の実戦1は準備別95.5／68.5／79.5%、実戦2は77.5／81.0／74.0%。万能ではなく準備選択に大きな差が残る。ただし他系統にも財源対策有利の傾向があり、選択肢の固定化はIssue #7で継続確認する。

全所持の地域は実戦2で行政より6.0、裏人脈より11.3ポイント高い。得意分野の差として暫定維持するが、人間のプレイで代替デッキを選ぶ理由があるか確認が必要。財源中心で地域が最高ではないことだけで、全案件のバランスがよいとは判断しない。

## 解釈と限界

12候補・選定用20回という小規模探索であり、最強デッキを発見した保証はない。全所持と2枚追加は別々の候補群なので、全所持の測定値が必ず高くなるわけではない。新しい測定乱数を使ったため、以前の95.8%と今回の初期96.0%の差は性能変更ではない。

各セル200回。勝率約80%の単一セルの95%区間はおおむね±5～6ポイント。準備別の試行は同じ種を共有するため、平均値を独立600回の結果として扱わない。小さな差を確定的な優劣と断定しない。

ボットの方策、手札超過時の自動捨て方、カード順、探索候補に依存する。全6属性の混成、補充・回復・無効化を最大化した手動構築、連続報酬キャンペーン、支持基盤、未実装カードは未検証。Issue #1/#2は閉じない。

入門再戦で収集デッキの勝率が高いことは許容する。成長を感じる場所として扱い、その数字を下げるために初期構成を弱くしない。次案件でカード資産に合わせた難易度を検討する。

## 次ステージの進め方

題材・ストーリー・主要論点の案出しは今回の確認後から進められる。全ゲームの数値バランス完成を待つ必要はない。ただし敵カードの数値確定前に次を揃える。

1. 到達時のカード資産を明示し、初期／少数追加／収集構成を別々に比較する。
2. 論点構成を変え、地域＋報道の得意分野と他属性の得意分野を作る。特定デッキ専用の無効化敵は設けない。
3. 準備選択で本戦が変わることを確認し、敵火力の一律増加だけに頼らない。
4. 本案件と新案件を同時に回帰比較し、人間の試遊で「考えて勝てるか」を確認する。

```sh
npm run compare:collection
CANDIDATES=1 TRAIN=1 BUDGETS=starter REPORT_PATH=reports/collection_starters_v14.json node tests/collection_v14.cjs
npm test
```

`reports/collection_v14.json` に選定候補の得点、使用カードID、測定結果、勝敗列、ソースSHA256を保存。`reports/collection_starters_v14.json` は同乱数の初期比較。初期2属性の全カードを使う条件の検証であり、全属性全カードの評価ではない。
