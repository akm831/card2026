# v06の実装状況

## 実装済み

1案件の全フロー、4論点（財源・議会・地方・報道）、3準備選択、成功時4敵カード差し替え、準備敗北でも本戦進行、戦闘ごとのHP・山札リセット、恒久カード報酬と重複交換、再挑戦、ブラウザ保存。

通常カード24枚＋人物6枚＋負担カード1枚。4初期デッキ。全カードに属性とタイプ。人物は行政2枚使用の防御、配置時の政治割引、予告変更ドロー、経済使用時の次ターン防御、地域回復と救援、裏人脈の順序変更と妨害割引。

敵の人物干渉は能力停止と次の手番への手札戻し。人物の配置解除は一時退場し、再登板で回収可能。疑惑は敵の山札へ混ぜ、次ターン以降の予告に現れる可能性。準備戦の疑惑は本戦へ持ち越さない。

## 設計

単体HTML内で `C` にカードデータ、`ISSUES` に論点、`PREPS` に準備戦を定義。カード効果は `effects` の `{op, n, issue, ...}` として保持し、`effect()` が解決する。敵の予告も `cost` と `effects` を持つ行動オブジェクト。将来の共有を意識した入口であり、現時点で完全なPvP共通エンジンではない。

Undoは戦闘と乱数seedを深いコピーで復元。敵ターンを確定すると履歴を破棄。勝利報酬もターン確定まで保留。セーブキーは `seikyoku-v6`。

## 試作上の仮決定

論点は4種。地方は直接対策できない論点。準備は1戦。人物は各属性1人。弱体化は4カードの差し替え。属性数制限・固定ペアボーナスなし。上級は敵HP＋8。

## v07追加仕様

全属性にコスト2攻撃。成長済み同属性人物が有効なら攻撃＋6。人物配置で防御3。行政は通常カード累計2枚、報道は予告介入累計2回、ほかは同属性通常カード累計3枚で1段階成長。進捗は battle.growth に人物ID別で保存。手札戻し・配置解除でも保持し、戦闘ごとにリセット。停止中は進捗・成長能力を発動しない。成長後は各ターン最初の同属性カードへ個別能力が反応。即時成長効果もある。ブロックは持ち越さない。

投資の追加ドローを2枚から1枚へ、財務アドバイザーの防御予約を基本2・成長後追加1へ変更。最新表示・カードデータはv07を基準とする。上記v06数値は履歴。

## v11 差分

手札は双方初期5・以後1、使用しないカードは保持。プレイヤーは7枚超過時に捨てるまで使用とターン確定を停止（Undo可能）。敵は7枚を超えると攻撃/コスト評価が低いカードを捨て、予告に使用したカードだけを終了時に消費。無効化されたカードも消費、延期されたカードは最初の予約時に消費し、再解決時には二重消費しない。

基本3コストは上限ではなく、投資・借り等の効果で増える。予備資金は翌ターン通常ドローを0枚にし得る。本人の手札は固定5枚に補充しない。

v11保存キーはseikyoku-v11。旧版のキーは変更しない。新規開始はユーザーの確認後に進行・所持を消去し、試遊メモのみ保持。自動プレイはVMのゲーム関数を呼び、DOMは代替オブジェクトである。実ブラウザの描画確認は別途必要。

## v12 敵AI

src/enemy_ai.jsの純粋関数へ公開盤面＋敵手札＋延期行動を渡す。手札最大7枚なので128通り以下の部分集合を走査。各カードは配列位置で選ぶため、同名カード2枚も別々に選べる。予告の通常行動は取り消されても消費、延期は初回予約時のみ消費という規則を維持。

防御は敵行動解決時に付与され、次のプレイヤー手番を守る。評価では実際の直近HP損失から予測し、プレイヤーの非公開攻撃カードを参照しない。勝利が見込める攻撃を優先するが、予告後の防御・無効化は予測しない。通常・上級は同じ思考で、従来の上級本戦攻撃＋1のみ維持。敵は多手先の最適探索をしない。
