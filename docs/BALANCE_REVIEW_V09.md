# v09：ぶれ・準備効果・プレイ手順の切り分け

## 方法

数値は変更せず、固定したv09の本戦のみを比較。4デッキ×2難易度×4条件（無対策、財源、報道、議会）×2プレイ方針×300回＝19,200戦。

準備成功を直接設定して本戦を開始する対照試験。準備戦の勝敗・コストを含まない。過去の「準備戦から通して遊ぶ」結果とは条件が異なる。同じ試行番号なら同じseedから本戦を開始。収集後の強化はなし。

単純bot：人物優先、最初の使用可能カード・対象。
予告対応bot：現在の予告に対し、防御で防げる量、攻撃、回復、成長、ドロー、次ターン投資などを評価し行動を選ぶ。非公開の山札や敵の手札を得点判断に使わない。行動評価を試算する際の乱数・戦闘の復元を検証。先のターンまで最適探索するbotではなく、人間の代用・理想的戦略の証明でもない。

95%区間はWilson法。固定疑似乱数サンプルでの参考推定で、全プレイヤー母集団の信頼区間ではない。JSONには勝数・区間・ターン数・勝利時HP・成長率・同一seedで対策により勝敗が入れ替わった数を保存。タイムアウトは全条件ゼロ。

## 判断

1. 以前の地域型上級の低勝率は、プレイ手順の影響も大きい。無対策でも32.3%→89.0%。報道対策は35.0%→87.3%。デッキがそもそも攻略不能とは言えない。
2. 財源対策は予告対応でも強い。上級の裏人脈は無対策68.3%→財源89.3%。他の対策は69%前後。単なる引きのばらつきとして許容する差ではない。
3. 通常は予告対応で行政・地域・経済がほぼ全勝。v09は判断を工夫すると易しすぎる傾向があり、最終的な目標バランスへ到達していない。
4. 裏人脈は予告対応でも通常79〜91%、上級68.3〜89.3%。前の単純botで見えた強弱の順位は、プレイ方針で変わる。

## 次の調整優先順位

- 財源論点の攻撃＋防御の同時作用と、その対策による改善幅を見直す。財源対策だけが正解になる状態を解消する。
- 報道・議会の対策にも、人物エンジンが持続する／反証の機会を作るなどの意味を持たせる。
- 敵攻撃の一律増加を避け、攻撃と防御の使い分け・人物保護を要求する本戦にする。
- 通常・上級を両botで比較し、初期デッキによる著しい不利と、予告対応で全勝する状態を同時に監視する。

この作業では原因を切り分けるためv09のゲーム内容は変更していない。人間の試遊、引き事故の頻度、準備の選択を納得して行えるかは引き続き確認が必要。
