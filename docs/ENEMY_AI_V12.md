# v12 敵AIの変更と自動プレイ結果

## 今回の変更

敵のデッキ・カード性能・双方HP30・基本3コスト・初期5枚/通常1枚/手札保持は変更していない。変更したのは行動選択と人物の対象選択のみ。

- 最大7枚の手札から、3コスト内で使えるすべての組み合わせを評価。延期済み行動を先に確保する。
- 攻撃：公開HP・ブロックに対するダメージと、勝利につながる攻撃を評価。
- 防御：直近に敵が受けたHP損失から、次のプレイヤー手番の攻撃を推定。敵HPが低いと防御を重視し、推定攻撃を大きく超える防御の重複を避ける。
- 人物干渉：配置中の人物の能力・成長・進捗から対象を評価。能力停止は属性条件を守り、既に次ターンまで停止している人物へ重ねない。同じ人物への複数干渉も価値を重複加算しない。
- プレイヤーの手札・山札・乱数・次に引くカードを参照しない。予告後はそのターンの選択と対象を変更しない。

防御カードの効果は敵の行動解決時に発生し、翌プレイヤー手番を守る。今の手番の攻撃を遡って防がない。人物を手札に戻した際の成長は従来どおり保持する。

AIはsrc/enemy_ai.jsに分離。HTMLにも同じコードを同梱し、単独で動作する。同梱の一致をテストで確認する。

## 検証方法

旧v11と新v12を、4初期デッキ×2難易度×3準備×2プレイヤー方策×200乱数で各9,600案件、合計19,200案件比較。準備戦から本戦まで通し、準備に負けても本戦へ進む。全案件打ち切り0。

乱数の初期値・デッキ・プレイヤー方策をそろえているが、AI行動が変われば消費・再シャッフルが変わるため、以後の引きが常に同一とは限らない。予告評価方策は公開状態の単発行動を評価し、隠れたカードを読まない。簡易方策も併用。人間の試遊・実ブラウザの表示確認ではない。

## プレイヤー勝率（予告評価方策）

各値は3準備ごとの最小～最大。各準備200案件。50%付近の95%区間の目安は±7ポイントなので、1～数ポイントの変化を改善の証拠と断定しない。

## 判定・残る課題

組み合わせ選択・条件に合う成長人物の優先・防御と攻撃の使い分けを実装でき、予告ターン当たりのコスト使用は少し改善した。しかしプレイヤー勝率は多くの構成でほぼ同じで、新AIが一律に強くなったとは言えない。敵が毎ターン1枚しか補充しないため、そもそも選択肢が少ないターンが多い。

地域＋報道は通常で依然高勝率。経済も強く、AI更新だけで系統差は解消しない。一方、初期デッキが通常で壊滅的な勝率になる結果は出ていないため、カード性能を同時に変更せず人間の確認へ進める。

直近のHP損失だけで防御を推定するので、ブロックで完全に防いだ攻撃や温存中の攻撃を正確には読めない。予告後の人物展開や無効化も見込まない。人物回収・反証公開等を含む複数手順の最適探索はしない。敵も1枚ドローというルール、収集後の追加ドロー型の優位はv11の未解決点として残る。

## 回帰・AI単体確認

旧版からの回帰とv12の保持・Undo・保存・延期・成長・予告対象固定が通過。AI単体では以下を確認：コスト内の組み合わせ、低HP時の防御、勝利につながる攻撃、成長人物優先、能力停止の属性条件と重複防止、過剰防御、延期予算、入力を変更しないこと。同じ敵手札・公開盤面でプレイヤーの非公開手札・山札を変えても予告は変わらない。

## 人間が確認する場面

1. 成長した敏腕官僚と未成長人物を配置し、更迭要求の対象を確認。
2. 敵HPが低くなったときに防御する場面と、こちらを倒せる攻撃を優先する場面を確認。
3. 予告を見て人物を置いた場合、対象が勝手に変わらないことを確認。
4. 旧版と比べて、敵が賢く感じるか、狙われる人物を守る判断が増えるかを試遊メモへ記録。

v12も検証用試作。実ブラウザ描画・スマートフォン操作・人間の体感は未確認。
