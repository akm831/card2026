# Godot UI03：文字の太さ・はみ出し修正

UI02の `variation_opentype={"wght":650}` はGodot4.6でレンダリング側へ太さが伝わっていなかった。実行時の比較で文字列キーでは座標辞書が空、数値タグではweight700が返ることを確認。`TextServer.name_to_tag("wght")` をキーに変更した。設定値だけではなく実際のTextServerの座標を回帰テストに追加。

ラベル・ボタンにクリップ/省略を設定。状態案内と操作ボタンを別行にし、長い案内が操作ボタンを押し出すのを防ぐ。カード全文は詳細小窓から確認可能。手札の仮絵領域を少し縮め、太字で広がる文字のために余白を確保。

1280×720・1560×720・1536×709で、7枚/3人物/3予告、詳細選択、長い案内文、勝利確定、8枚超過と捨てる操作を座標で確認。レンダリング側weight700を確認。4デッキの操作・Undo・ターン終了・保存再開もheadlessで確認。新APKはローカル署名検証済み。実機の目視・音・指操作は未確認。
