# 政局の手札 — 霞が関カードバトル

政治・行政を題材にしたシングルプレイヤー向けカードゲームの試作です。人物・組織・不正の設定は架空です。

## 遊び方

最新は `prototypes/kasumigaseki_cards_v09.html`。ダウンロードしてブラウザで開けます。依存ライブラリ・ビルド不要。ブラウザ保存が許可された環境では進行を自動保存します。v05とv06の保存データは独立です。

ローカルサーバーを使う場合：

```sh
python3 -m http.server 8000
```

`http://localhost:8000/prototypes/kasumigaseki_cards_v09.html` を開いてください。

## 現在の検証対象

v06「夢の超特急」1案件：案件分析→デッキ編成→準備戦3択から1戦→敵の論点カードを弱い版へ差し替え→国会決戦→恒久カード報酬→後日談。

行政＋政治、地域＋報道、裏人脈＋政治、経済＋行政の初期デッキで比較できます。戦闘はHP30、毎ターン3コスト、人物最大3人。敵行動予告・対象選択・ターン確定前のUndoを実装。

## ファイル

- `prototypes/`：v01〜v09の実行可能なHTML。旧版は比較用。
- `docs/SPEC.md`：次回試作の決定事項・保留事項・PvP設計方針。
- `docs/IMPLEMENTATION.md`：実装状況・設計・制約。
- `docs/HISTORY.md`：試作の経緯。
- `docs/TESTING.md`：自動検証方法と結果の読み方。
- `tests/`：v05/v06の回帰テストと簡易自動プレイ。
- `reports/`：自動プレイの結果。

## 検証

Node.jsを用意し、リポジトリのルートで実行します。npm依存パッケージはありません。

```sh
npm test
npm run balance:v06
```

自動プレイの勝率は人間の勝率ではありません。v06では経済型が強く、行政型は難しめです。実ブラウザでの画面・操作確認と人間による面白さの検証は未完了です。

## 今後

まずv06の論点・準備選択・人物エンジンを検証します。選挙、支持基盤の複数装備、Godot移行、PvPは後続。新しい管理リソースは増やさず、カードバトルを中心に進めます。

## v07：人物の成長とコスト2

人物は戦闘内で1段階成長し、進捗はターンをまたいで保持します。配置時防御、成長後の能力、同属性のコスト2攻撃＋6を実装。成長は能力停止・手札戻しでは失わず、次の戦闘でリセットします。コスト2攻撃を全属性に復活させました。保存はv07専用です。

## v08：試遊で判明した表示・仕様の修正

双方HP30（上級も固定）。上級は敵攻撃＋1。カードコストを白文字とラベルで表示。敵予告へ論点を表示。論点軽減の対象がないカードは無効化。初期デッキは名前の2属性を各10枚に統一。敏腕官僚は成長時防御5に加え、成長後の各ターン開始で防御5。更迭要求は全人物、造反工作は政治人物を対象。予告対象は予告作成時に固定。v08専用保存。

## v09：戦闘バランスの再検証

双方HP30と官僚の成長後開始防御5を維持。コスト2攻撃・成長攻撃ボーナスを軽減（＋6→＋4）、資料答弁と予備資金を防御7へ、資金調達をコスト1・コスト回復1・ドロー1・負担追加へ調整。本戦の未対策財源・地方攻撃は次手番の防御も得る。財源対策後も防御1を保持。上級は本戦攻撃＋1、準備戦は通常と共通。詳しいテスト結果はdocs/TESTING.md。財源対策時の高勝率はまだ残る。
