# 政局の手札 — 霞が関カードバトル

政治・行政を題材にしたシングルプレイヤー向けカードゲームの試作です。人物・組織・不正の設定は架空です。

## 遊び方

最新は `prototypes/kasumigaseki_cards_v14.html`。ダウンロードしてブラウザで開けます。依存ライブラリ・ビルド不要。ブラウザ保存が許可された環境では進行を自動保存します。v05とv06の保存データは独立です。

ローカルサーバーを使う場合：

```sh
python3 -m http.server 8000
```

`http://localhost:8000/prototypes/kasumigaseki_cards_v14.html` を開いてください。

## 現在の検証対象

v06「夢の超特急」1案件：案件分析→デッキ編成→準備戦3択から1戦→敵の論点カードを弱い版へ差し替え→国会決戦→恒久カード報酬→後日談。

行政＋政治、地域＋報道、裏人脈＋政治、経済＋行政の初期デッキで比較できます。戦闘はHP30、毎ターン3コスト、人物最大3人。敵行動予告・対象選択・ターン確定前のUndoを実装。

## ファイル

- `prototypes/`：v01〜v14の実行可能なHTML。旧版は比較用。
- `docs/SPEC.md`：次回試作の決定事項・保留事項・PvP設計方針。
- `docs/IMPLEMENTATION.md`：実装状況・設計・制約。
- `docs/HISTORY.md`：試作の経緯。

- `reports/`：自動プレイの結果。

## 検証

Node.jsを用意し、リポジトリのルートで実行します。npm依存パッケージはありません。

```sh
npm test
npm run balance:v06
```

自動プレイの勝率は人間の勝率ではありません。v06では経済型が強く、行政型は難しめです。実ブラウザでの画面・操作確認と人間による面白さの検証は未完了です。

## 今後

まずv06の論点・準備選択・人物エンジンを検証します。選挙、支持基盤の複数装備、Godot移行、PvPは後続。新しい管理リソースは増やさず、カードバトルを中心に進めます。

## v07：人物の成長とコスト2

人物は戦闘内で1段階成長し、進捗はターンをまたいで保持します。配置時防御、成長後の能力、同属性のコスト2攻撃＋6を実装。成長は能力停止・手札戻しでは失わず、次の戦闘でリセットします。コスト2攻撃を全属性に復活させました。保存はv07専用です。

## v08：試遊で判明した表示・仕様の修正

双方HP30（上級も固定）。上級は敵攻撃＋1。カードコストを白文字とラベルで表示。敵予告へ論点を表示。論点軽減の対象がないカードは無効化。初期デッキは名前の2属性を各10枚に統一。敏腕官僚は成長時防御5に加え、成長後の各ターン開始で防御5。更迭要求は全人物、造反工作は政治人物を対象。予告対象は予告作成時に固定。v08専用保存。

## v09：戦闘バランスの再検証

双方HP30と官僚の成長後開始防御5を維持。コスト2攻撃・成長攻撃ボーナスを軽減（＋6→＋4）、資料答弁と予備資金を防御7へ、資金調達をコスト1・コスト回復1・ドロー1・負担追加へ調整。本戦の未対策財源・地方攻撃は次手番の防御も得る。財源対策後も防御1を保持。上級は本戦攻撃＋1、準備戦は通常と共通。詳しいテスト結果はdocs/TESTING.md。財源対策時の高勝率はまだ残る。

## v09比較検証

`npm run compare:v09` で無対策と各対策・単純botと予告対応botを比較できます（19,200戦、数分）。`docs/BALANCE_REVIEW_V09.md` に結果と判断、`reports/compare_v09.json` に詳細。ゲーム数値は変更していません。

## v10：人による試遊の判断支援

数値はv09と同じ。カードの「効果を確認」で使用後の見込み被ダメージと実攻撃ダメージを表示。対象選択中の予告を強調し、人物の成長連携・成長能力の発動をログに表示。「試遊メモ」で難しさ、迷ったカード、準備の理由、人物の貢献を記録・JSON出力できます。外部送信はなし。手順はdocs/PLAYTEST_V10.md。

## 手札保持の比較検証

`npm run test:hand-rules` で現行・自分1枚・自分2枚・双方1枚を比較。結果はdocs/HAND_RULES_REVIEW.mdとreports/hand_rules_v10.json。現在のカードに通常ドロー1枚をそのまま適用すると大きな属性差が出たため、正式版の手札ルールは変更していません。

## v11：手札持ち越しと毎ターン1枚ドロー

双方初期5枚、以後通常1枚。未使用カードを保持し、効果による追加ドローはデッキ構築の選択肢として残します。手札上限7枚、プレイヤーは超過分を選んで捨てます（Undo可能）。敵も上限7枚、予告に使ったカードのみ消費します。双方HP30・基本3コストは維持。

重複人物を初期デッキから減らして、各属性に通常カードを1種類追加。コスト2の攻防兼用カード、裏人脈の疑惑、地域・報道の循環を調整。「最初から」で別の初期デッキを試せます（収集・進行の削除確認あり）。v11保存は旧版と独立です。

詳細は [v11検証・懸念点](docs/BALANCE_REVIEW_V11.md)。再現は `npm run balance:v11`。自動プレイは人間の勝率を保証しません。実ブラウザの表示確認は未完了です。

## v12：公開情報で判断する敵AI

敵が3コスト内の全組み合わせを比較し、攻撃・翌手番の防御・人物への干渉を別々に評価します。成長した人物を優先して狙い、条件外・停止済みの人物は能力停止の対象から除外。延期済み行動は先にコストを確保し、予告と対象は公開後に固定します。プレイヤーの手札・山札・次のドローは参照しません。

カード性能・HP・ドロー方式はv11と同じ。v12保存は独立。AI本体は `src/enemy_ai.js` に分離し、HTMLにも同じコードを同梱するため、単独で開いて遊べます。同期はテストで確認。比較結果は [敵AI検証](docs/ENEMY_AI_V12.md)、再現は `npm run compare:enemy`。

## v13：入門から実戦へ

最初の案件を入門用とし、単純使用ボットで初期4デッキの勝率75〜85%を目安に調整。予告評価ボットは別の熟練参考値として残す。初期デッキの使い道が少ない枠を攻撃・回収へ交換し、地域の防御/介入と経済の補充効率を調整。双方HP30・基本3コスト・手札保持/通常1枚は維持。

1回クリアで財源・採決重視の実戦1、2回クリアで地方・報道重視の実戦2を選択可能。同じ題材の再戦条件であり、独立した歴史案件3本ではない。本戦は実戦1攻撃＋1、実戦2はコスト2の追及をさらに＋1と論点配分の変更で難しくする。準備戦の基礎攻撃は共通。報酬はランダム2枚＋自由選択1枚。選択報酬と所持カードを使って次の論点へ対策できる。

詳細は [入門/実戦検証](docs/PROGRESSION_V13.md)。`npm run balance:v13`と`npm run compare:rebuild`で再現。旧版と保存は独立。実ブラウザと人間の試遊は未確認。

## v14：地域＋報道の補充効率を切り分け

v13の人物ドロー/人物回復/成長攻撃と、通常カードの補充/予告対策を別々に外して比較。今回の条件では人物単独より通常カード補充の影響が大きかった。記者説明は防御3＋次ターンに追加1枚、裏取りはコスト2・ドロー2へ。新聞記者の介入/成長時/攻撃ドローは合わせて各ターン1枚まで。通常カードのドローは別枠。

入門の直接攻撃を公開討論7・沿線説明会8へ補強。世話役の回復と成長攻撃＋4、HP30、通常1枚、入門/実戦の構成は維持。v14保存は独立。詳細は [切り分けと調整結果](docs/REGIONAL_BALANCE_V14.md)。`npm run balance:v14`、`npm run ablate:regional`で検証。
